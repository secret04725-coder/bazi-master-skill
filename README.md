# bazi-master · 八字命理深度分析 Skill

> 精确排盘（代码计算，非 LLM 推算）× 19 章深度分析 × 九部经典引用 × 历史校准实证 × 精美 HTML 报告

一个面向 AI Agent 的子平八字分析系统。排盘交给确定性代码，论命交给经典规则库，结论交给历史校准来验证——三层设计保证输出既专业又可被检验。

## 设计理念：为什么不让 LLM 直接算命

**1. 排盘必须是确定性计算。**
日柱推算涉及公元纪日取模运算，月柱涉及节气换月，时柱涉及五鼠遁元——LLM 心算这些极易出错，而一个排错的盘会让后面所有分析全部作废。本 Skill 强制使用 `paipan.py` 计算（基准点 1900-01-01 = 甲戌日，已用 1949-10-01 = 甲子日交叉验证）。

**2. 论命必须有典可依。**
报告中每一个关键判断都标注经典出处（穷通宝典、滴天髓等），不允许 AI 凭"语感"下断语。分析框架的每一章都绑定了主引用典籍（见下文章节表）。

**3. 结论必须可被验证。**
采用《千里命稿》的实证方法论：报告最后一章会基于命局推导 3-5 件命主**已经发生**的事件（大运交接年的变动、流年冲合引动的节点、性格特征），请命主对照反馈。3/5 以上准确才视为排盘与用神判断成立，否则回头检查时辰。

## 与纯 LLM 八字工具的区别

| 特性 | 本 Skill | 纯 LLM 推算 |
|------|----------|-------------|
| 排盘方式 | Python 确定性计算，可交叉验证 | LLM 心算，日柱极易出错 |
| 调候用神 | 穷通宝典逐月查表，每报必析 | 常被遗漏 |
| 经典引用 | 每个关键判断标注出处 | 无出处，凭语感 |
| 结论验证 | 历史校准章，命主可证伪 | 不可验证 |
| 输出 | 19 章可视化 HTML 报告 | 纯文本 |
| 农历/真太阳时/夜子时 | 内置处理规则 | 通常忽略 |

## 已知精度限制

- 脚本节气采用近似日期，节气日 ±2 天出生需联网核实真实节气时刻（SKILL.md 已内置该规则）
- 起运年龄默认 9 岁近似，精确值需按节气天数÷3 重算（大运干支序列本身准确）
- 真太阳时校正依赖出生地经度，边界时辰（±30 分钟）建议双版本对照
